# VeilBreak demo

Paste a prompt and see what is hiding inside it, then how a safety classifier
judges it with and without decoding.

- Prompts are not stored.
- Research demo: it targets encoded and invisible-character attacks only, not
  roleplay jailbreaks, and the classifier makes mistakes.
- Free hosting sleeps when idle, so the first visit can take a minute.
